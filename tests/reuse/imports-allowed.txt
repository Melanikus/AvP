# What a test's program may call outside itself and still be class A, and what makes it class B at most (tests/reuse/Reuse.psm1, Get-ImportClass).
# Written 2026-11-11 by Melanikus for the AvP port, after Secondary's attacker's reading of the CI plan's step 4 (C2: decide the class from the
# built program's own import table, against a list taken from an empty test).
#
# A line is "allowed DLL!Function" or "files DLL!Function", as dumpbin /imports names them (the DLL in capitals). A program that imports
# anything not here is class C, and always runs. Adding a line is a change to the gate itself (CODEOWNERS): add only a function whose answer
# can't change from one run to the next, and say why in the commit.
#
# ---- What every test imports before main and after it: the empty test's own (tests/reuse_empty_probe_test.cpp, built 2026-11-11 with
# Visual Studio 18, tools 14.51.36231). Some of these read a clock or the process's numbers (QueryPerformanceCounter, GetSystemTimeAsFileTime,
# GetCurrentProcessId, GetCurrentThreadId): the C runtime's start-up code uses them for its stack guard. As every program has them, the
# import table can't tell that use from a test's own, so a test's own use of them is caught by the text scan (kOtherWays) instead.
# tests/reuse/record.ps1 checks in every run that the empty test still imports nothing more than these; if it does, no test is class A
# until this list has been read again.

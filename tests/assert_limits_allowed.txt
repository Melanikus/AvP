# Asserts on limits that have been read, and why each is safe, for tests/assert_limits_test.cpp. Written 2026-11-05 by Melanikus for the AvP port.
#
# Each line is: the file | what the assert says | why it's safe.
#
# Before adding a line: an assert is left out of the game players run, so it guards nothing. If a level, a model, a save, a picture, another player or anything else from outside the code can reach
# it, it needs a real check. Add a line only when nothing can, and say why, so that someone reading this years from now can check the reason for themselves.
#
# Two kinds here are not yet safe, and say so: a save file can still reach the weapon slots and path numbers (card SAVE-2), and a network message can still reach one damage number until the branch
# that fixes it lands.

mldsa-native, and the licence the game takes it under

What it is: mldsa-native version 2.0.0, from the pq-code-package project (github.com/pq-code-package/mldsa-native), built into the game for
ML-DSA-87 (FIPS 204), the check of the post-quantum half of each signature the game is given.
vcpkg builds it from source, unchanged, with this project's own settings: vcpkg-overlay-ports/mldsa-native says how.
